# 提交 Commit

Commit 是 Git 里最核心的概念之一。

大白话说：一次 commit 就是给项目拍一张快照。

## Commit 里有什么

一次提交通常包含：

- 这次改了哪些文件
- 每个文件改了什么
- 谁提交的
- 什么时候提交的
- 提交说明

## 为什么提交信息很重要

提交信息就是以后看历史时的路标。

比如这个就比较清楚：

```text
Add weekly GitHub trending report
```

这个就比较模糊：

```text
update
```
