# 07 常用命令速查

这一篇适合当小抄用。

## 查看状态

```powershell
git status
```

看看哪些文件改了、哪些文件还没提交。

## 添加到暂存区

```powershell
git add README.md
git add .
```

`git add README.md` 是只添加一个文件。  
`git add .` 是添加当前目录下所有改动。

## 提交

```powershell
git commit -m "说明这次改了什么"
```

提交信息最好写清楚一点。以后看历史记录时，自己也能看懂。

## 上传到 GitHub

```powershell
git push
```

把本地提交上传到远程仓库。

## 从 GitHub 拉取

```powershell
git pull
```

把远程仓库的新内容拉到本地。

## 看历史

```powershell
git log --oneline
```

用一行显示一次提交，看起来更清楚。

## 看远程地址

```powershell
git remote -v
```

## GitHub CLI 常用命令

```powershell
gh auth status
gh repo view
gh browse
gh pr list
gh issue list
```

## 最常用工作流

```powershell
git status
git add .
git commit -m "更新内容"
git push
```
